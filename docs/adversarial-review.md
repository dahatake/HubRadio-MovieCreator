## 修正内容の概要

- 出力要素の出自を`OriginRef`へ統一し、元発言・承認素材・編集部文言を正しく区別した。
- `SourceSpan`例、VFR時刻の正本、文字起こし改訂、成果物キャッシュ依存を修正した。
- Stage 0/1を最小構成へ戻し、Temporal、Kubernetes、OTIO、Cosmos DB HPK、C2PA、WORMを条件付き採用へ変更した。
- 横長短尺、告知版、納品一覧、手動縦型フォールバックを追加した。
- レビュー状態、権利警告、QC再試行、C2PA鍵運用を明確化した。
- 字幕、ランキング、リフレーミング、再現性の保証範囲を実装可能な規則へ限定した。
- 業務効果、性能、アクセシビリティ、PII、セキュリティ、復旧の評価計画を追加した。
- コマンド注入とアクセシビリティの一次資料、C2PAの調査時点releaseを追加・修正した。
