# ADR-0004: 公開区分とAI送信区分

- 状態: Accepted
- 決定日: 2026-08-27
- タスク: P-006

> [!IMPORTANT]
> 2026-09-02以降、社内限定成果物のfinal render前に人手review/approvalを必須にする部分は[ADR-0009](ADR-0009-source-only-defaults-and-automated-evaluation.md)が置き換える。社内限定既定、公開範囲の自動拡大禁止、Azure最小payload、AIだけで外部公開可にしない原則は維持する。以下は決定時点の履歴である。

## 決定

案件、素材、span、編集版、成果物に公開区分を持たせ、下位要素は親より広い公開区分へ自動昇格できない。

| 区分 | ローカル閲覧 | 最終出力 | Azure送信 |
|---|---|---|---|
| 社内限定 | 権限保持者のみ | 社内用のみ | 既定禁止。人が選択・マスク・確認した文字起こしspanだけ例外候補 |
| 特定グループ限定 | 指定役割のみ | 指定保存先のみ | 既定禁止 |
| 外部公開候補 | 権限保持者のみ | 必須レビュー後 | 人が選択・確認した文字起こしspanだけ候補 |
| 外部公開承認済み | 権限保持者のみ | 承認digestに限り許可 | 必要最小限の文字起こしspanだけ候補 |
| 公開不可 | 権限保持者のみ | 禁止 | 禁止 |
| 判定待ち | 権限保持者のみ | 外部用は禁止 | 禁止 |

## Azureへ送信できるデータ

全条件を満たす場合だけ送信候補にできる。

1. 利用者が目的と対象spanを明示選択した。
2. 送信payloadを画面で確認した。
3. PII、秘密、内部URL、認証情報、不要な固有名詞を候補検出し、利用者が解消した。
4. 送信先、Azureリージョン、モデルID、保持条件が表示された。
5. 音声、動画、画像、ファイルパス、ローカルSID、内部案件IDを含まない。
6. `ModelRun`へ入力digest、送信データ区分、送信先、モデル版、応答digestを記録する。

## 既定禁止

- 元動画、代理動画、音声、フレーム、資料画像のクラウド送信
- 案件の全文文字起こしを一括送信
- バックグラウンドでの無確認送信
- APIキーのファイル、DB、ログ、バックアップへの保存
- AnthropicインフラでhostされたClaudeの利用
- AI出力による公開区分、権利、機密性、承認の自動確定

## 出力先規則

- 最終出力前に公開区分、素材権利、未解消注意、承認digestを同期再検査する。
- 社内限定表示を削除しただけで外部公開可能とはみなさない。
- `Published`は外部公開処理ではなく、既に行われた公開事実の記録である。
- 人が案件・素材・span・編集版の公開範囲を拡大する場合、変更権限と理由を監査し、新しい子`CompositionVersion`を作る。既存承認を引き継がず、拡大後の区分に必要なPerformer/Content/Brand/Rightsレビューを再実行する。

## 監査

送信本文を通常ログへ複製しない。監査には必要最小限のdigestと分類情報を保存し、人が選択した送信内容そのものは案件の保護された証拠領域へ保存するか、保持しない方針をP-007で決める。
