## 1. 概要

### 1.1 事業背景

Hubらじおは、主に 16:9 の横長で収録される 10〜20 分の企業内向けトーク・インタビュー動画です（SRC-001 §2.1）。編集者が動画を最初から最後まで見て使える場面を手作業で探し、カット・文字起こし・字幕・テロップ・画角変換を個別に行っており、長尺版と短尺版を別々に編集するため、編集が特定の担当者に集中し、継続的な制作が難しい状態です。元動画 1 本を指定するだけで、社内向けの長尺版・短尺版・字幕・サムネイル・付帯情報を自動生成するソフトウェアで、この問題を解きます。

### 1.2 目的

| ID | 目的 | 成功指標 | 測定方法 |
|---|---|---|---|
| G-001 | 元動画 1 本から、長尺版・縦型短尺版・字幕・サムネイル候補・付帯情報を自動生成する | 元動画の選択から編集開始までの必須操作が 1 回の確認に収まる。成果物 set（長尺・短尺・字幕・サムネイル）が 1 回の実行で生成される | 1 回の確認で開始できること: NFR-UX-001 の AC-113。成果物 set: FR-001 の AC-049、FR-008 の AC-001、FR-009 の AC-057、FR-010 の AC-002、字幕 FR-012 の AC-060、サムネイル FR-021 の AC-069、出力 FR-031 の AC-079 を System Test・結合試験で確認 |

### 1.3 事業妥当性の判定

判定: 条件付き。根拠は元文書の背景と課題（SRC-001 §2）だけで、費用・効果の数値の出典がありません。条件: 編集時間の削減など効果の測定方法を、利用者が別途定めること（§10.3 A-003）。

## 2. 対象と対象外

対象（元文書 §4.1）: 単一 EXE の 1 操作起動、source-only quick start、版付き既定設定と設定画面、動画の取り込み、音声解析・話者識別・文字起こし、不要区間の検出、トピック・見どころの抽出、長尺版・縦型短尺版・字幕・強調テロップ・オープニング／エンディング・BGM と効果音・サムネイル・クイズ形式の生成、Opening／Closing 動画の結合、Project 一覧・Job の管理、プレビュー・修正・自動代理評価、出力、編集履歴と元動画との対応管理。

対象外（元文書 §4.2。初期リリース）: 外部への公開・直接投稿、出演者の発言内容の自動変更・実在人物の映像合成、権利未確認の外部素材の自動挿入、AI だけによる機密・法務の最終判断、ライブ配信中の編集、複数 Windows アカウント間の権限分離、インストーラー・自動更新・アンインストーラー、Windows 以外・Windows 10・ARM64。

## 3. 前提・制約

### 3.1 既定制約（要求定義プロンプトの常設方針）

- ui_policy-1 利用者がレイアウトを変更できるモダンな UI（決定状態: 承認済み・既定制約）。具体化は NFR-UX-005（配置の変更）と NFR-UX-002（保存・復元・既定への復元）で、どちらも MUST・承認済み（承認依頼 2026-10-08）。FR-061・FR-063 は、この制約の適用範囲を本文に持つ。
- ui_policy-2 ペルソナごとの既定の情報表現（決定状態: 承認済み・既定制約）。具体化は NFR-UX-003（承認済み（承認依頼 2026-10-08））。
- 既定制約（元文書 §1・§4.2・NFR-004）: 出力は社内限定かつローカル成果物を既定とする。元動画は変更しない。決定論的で意味を変えない規則だけを自動適用する。対象は対応 Windows の標準ユーザー 1 名。

## 5. 利用シナリオ

- 主な流れ: 元動画を選択して Project を作成 → 設定が自動補完される → 1 回の確認で編集開始 → ジョブの状態を確認 → 仕上がりを Job ごとに見る → 出力。
- 代替: 設定を変えた Job を複数作り、映像と設定を比較する（FR-055・FR-063）。Opening／Closing を結合する（FR-035）。
- 失敗と復旧: 編集開始や自動編集が失敗したとき、原因と対応策を表示し、可能なものは自動修復する（FR-036・FR-047）。
- 変更と取消: Project の名前変更・削除、Job の取消・再試行（FR-037・FR-040・FR-046・FR-061）。

## 6. 要求

### 6.1 機能・非機能・ブランド要求

優先度の区分は、旧版 §16（SRC-002 の common.md §16）の Must／Should に従う。Should は FR-007・FR-011・FR-018・FR-020・FR-022・FR-025、それ以外は Must。§16 に明示のない FR-023・FR-024・FR-028 は MUST と仮定した（§10.3 A-002）。FR-007 と FR-010 は、§16 でそれぞれ「高度な見どころ・フック候補」（Should）と「9:16短尺候補を最大3本」（Must）に分かれるため優先度が異なる（§10.4 AU-005）。

#### FR-001 動画取り込み
- 要求: システムは、一般的な動画ファイルを元素材として登録できること。登録時に、ファイル名・再生時間・解像度・縦横比・フレームレート・音声トラックの有無・ファイル容量・作成日時・登録者を取得すること。破損、音声なし、極端な低解像度など、編集に影響する状態を検出した場合は警告すること。
- 決定状態: 承認済み（依頼 2026-08-26）　出自: 依頼原文　優先度: MUST（旧版の優先順位 §16 の区分を保持）
- 上位: G-001　出典: SRC-001（索引の行 FR-001）、SRC-002（詳細本文）
- 対象エンティティ: 元動画, 編集計画, 成果物　関係する状態: なし　参照パラメータ: なし
- 関連する既存資産: docs/catalog.md の該当行（未登録の項目は §10.4 の AU-002）
- 受入基準 AC-049: 利用者が動画ファイル 1 本を元素材として登録したとき、ファイル名・再生時間・解像度・縦横比・フレームレート・音声トラックの有無・ファイル容量・作成日時・登録者が記録・表示される。音声なし・破損・極端な低解像度の動画を登録したときは、その状態を示す警告が表示される。
  - 検証レベル: system

#### FR-002 文字起こし

- 決定状態: 承認済み（依頼 2026-08-26）　出自: 依頼原文　優先度: MUST（旧版の優先順位 §16 の区分を保持）
- 上位: G-001　出典: SRC-001（索引の行 FR-002）、SRC-002（詳細本文）
- 対象エンティティ: 元動画, 編集計画, 成果物　関係する状態: なし　参照パラメータ: なし
- 関連する既存資産: docs/catalog.md の該当行（未登録の項目は §10.4 の AU-002）

  - 検証レベル: integration
