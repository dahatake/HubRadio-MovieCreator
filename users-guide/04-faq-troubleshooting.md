# 困ったとき・安全のために・用語集

## 1. 困ったとき

| 症状 | 対処 |
|---|---|
| アプリが開かない／「Web UI を準備しています」のまま | 初回は1分近くかかることがあります。待っても進まなければ、アプリを閉じて開き直し、[開発者向けトラブルシューティング](../docs/dev/troubleshooting.md)を確認します |
| 右上が緑の丸にならない | アプリ内部とつながっていません。数秒待ち、直らなければ開き直します |
| ボタンを押しても画面が変わらない | 数秒〜1分待ってから画面を見直します。**最新状態を取得**も試します |
| 「操作を完了できませんでした」と出て編集が始まらない | 表示された原因と対処に従い、「もう一度試す（自動で再確認）」を押します。直らなければ開き直します |
| 「編集を開始」を押せない | 動画が選ばれているか、画面の案内（依存の準備中など）を確認します |
| 自動編集が失敗した | 「エラーの内容」の**対応策**を順に試し、**自動編集を再試行**を押します。繰り返す場合は動画の形式・長さ・空き容量を確認します |
| 「整合性の再確認が必要」と出た | 画面の案内に従い、**最新状態を取得**を押します。直らなければ開き直します |
| 字幕を直したのに動画が変わらない | 字幕の保存と動画の更新は別です。**再生成**を実行します |
| 設定を保存したのに動画が変わらない | 設定は次に作る Job にだけ使われます。**再生成**が必要です |
| 音量が大きい・小さい | 仕上がりの自動評価の音量項目を確認し、設定の「音声と素材」を見直して再生成します |
| 作業エリアが狭くて見づらい | ウィンドウを広げます（約 1280px 以上を推奨） |

それでも解決しない場合は [GitHub Issues](https://github.com/dahatake/HubRadio-MovieCreator/issues) へ連絡してください。**動画の内容、個人情報、機密情報、認証情報は書かないでください。** エラーコードは伝えて構いません。

## 2. よくある質問

**元の動画は変更されますか？** 変更されません。編集は非破壊で、元動画は上書きされません。

**動画は外部へ送信されますか？** 既定では、動画・音声・画像は端末の外へ送られません。

**AI が公開まで行いますか？** 行いません。外部公開と直接投稿は対象外です。

**自動評価が「未評価」です。問題ないですか？** 「人が確認していない」という意味です。問題なしの意味ではないので、必ず自分で再生して確認してください。

**Windows 以外で使えますか？** 対象は Windows 11（64ビット）です。

## 3. 安全のために

- 利用権を確認できない動画・画像・音楽・ロゴを外部公開しないでください。
- 顧客名・個人情報・未公開情報は警告されることがありますが、見逃すこともあります。公開前に自分で確認してください。
- 自動の字幕・要約・判定を、事実や法的な判断として扱わないでください。
- 社内限定の成果物を、外部公開用として使わないでください。

## 4. 用語集

| 用語 | 意味 |
|---|---|
| Project | 1本の元動画から成果物を作る作業のまとまり |
| Job | Project の自動編集 1 回の実行。設定を変えて何本も作れ、前の Job は残ります |
| 元動画 | 編集前の、選んだ動画ファイル |
| 長尺 / 短尺 | 全体を編集した動画／短く切り出した縦長（9:16）動画 |
| 16:9 / 9:16 | 画面の縦横比。16:9 は横長、9:16 は縦長（スマホ向け） |
| 字幕焼き込み版 / クリーン版 | 字幕が映像に入っている版／字幕のない版 |
| 字幕ファイル（SRT / VTT） | 字幕を別ファイルにしたもの |
| 文字起こし | 音声を文字にしたもの |
| サムネイル | 動画の表紙画像 |
| 自動代理評価 | 機械が確認できる項目（再生できるか、音ずれ、音量など）の自動チェック。人の確認の代わりではありません |
| 再生成 | 保存した設定や字幕修正を使って、新しい Job を作ること |
| 納品済み | 成果物のファイルが保存され、受領の証跡があること。公開可の意味ではありません |
| 社内限定 | 外部公開しない前提の区分（変更不可） |
